# CIN — Historical Archive

This directory preserves the pre-reset repository state.

## Archival rules
- Preserve legacy files and their relative paths when migrating them here.
- Do not delete historical implementations, specifications, certificates, workflows, or documentation during the reset.
- Record the source commit and a complete path inventory for every archival batch.
- Archived files are not active implementation or current requirements unless the new Main explicitly adopts them.
- Do not execute archived tests or workflows during the reset.

## Reset status
The archive destination and preservation policy are defined. The complete tracked-file migration is not yet complete; it requires a verified repository tree inventory so no files are omitted or overwritten.
