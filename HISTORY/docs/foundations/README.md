## Reading order

1. Read the civilizational need independently of CIN.
2. Read the individual participation principle and preserve the distinction between person, registration, node, and association.
3. Read the privacy and participation constraints.
4. Consult the existing CIN Foundational Principles for governing conceptual boundaries.

## Maturity

These documents establish research direction and design constraints. They do not establish that a global registry, universal legal obligation, or production network exists. Technical requirements, legal relationships, and implementation status must be specified and validated separately.
