# CIN Storage

User-space data and configuration are separated from installed code.

Proposed locations:
- Configuration: `~/.config/cin/`
- Installed Main: `~/.local/share/cin/Main/`
- Runtime data: `~/.local/share/cin/data/`
- Logs: `~/.local/share/cin/logs/`

The exact storage layout is subject to migration inventory and compatibility mapping.
